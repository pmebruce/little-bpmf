# 小小ㄅㄆㄇ · 注音探險隊

給 5–7 歲孩子的互動注音 PWA，無帳號、無廣告、無付費 API。

## v2 功能
- 聲音寶藏島：教育部注音錄音、三選一或四選一、錯題優先複習。
- 拼音彩虹橋：把注音積木排成字音，入門無聲調，進階含聲調。
- 聲調溜滑梯：一至四聲與輕聲辨識。
- 每回合五題、完成回合收集動物貼紙；答錯可提示重試，不扣分。
- 37 個正確且不重複的注音；區分「聽過」與「答對」。
- 官方字形與逐筆顯示；手指／滑鼠自由描寫（不自動評分）。
- 本機進度、每日目標、台灣中文語音選擇、可安裝圖示與離線快取。

## 發音與授權
37 個注音錄音內建，可離線播放。例字與聲調採裝置的 zh-TW / zh-Hant 語音，不以其他口音替代；沒有合適語音時顯示陪讀提示。字詞語音能否離線取決於裝置。

## 部署
延用既有 Cloudflare 靜態網站部署。根目錄就是網站輸出，無建置步驟、無依賴安裝；所有 URL 都使用相對路徑。GitHub Pages 子路徑同樣可用。

本機預覽：`python -m http.server 8000` 後開啟 `http://localhost:8000`。

## 進度與更新
v2 使用新的 `little-bpmf-v2` 儲存格式。v1 因符號對應錯誤，且點擊即加星，舊紀錄保留但不當成 v2 學習成果。

每次改版同步更新 `sw.js` 的 CACHE 版本。新版本完整快取後等待舊頁面關閉，避免遊戲中途混用兩版。安裝後請關閉所有舊分頁／主畫面 App，再重新開啟。資料不跨裝置同步；清除瀏覽器網站資料會移除進度。

5 歲模式限制為 14 個常用注音、三選一與一聲拼音；6、7 歲模式使用全 37 個符號及含聲調拼音。可依熟悉度自行選擇，不限制實際年齡。

## Cloudflare Pages 組態核對

- Git 儲存庫：`pmebruce/little-bpmf`
- 正式環境分支：`main`，啟用自動部署
- 建置命令：留空
- 輸出目錄：儲存庫根目錄（`.`）
- 根目錄：留空，使用儲存庫根目錄
- 建置監看路徑：`*`

部署後應看到「注音探險隊」首頁與 v2.0 頁尾。若正式環境仍顯示舊提交，先確認部署列表是否收到新的 GitHub 提交；瀏覽器重新整理不能取代伺服器部署。

GitHub App 若使用 Only select repositories，需包含 `little-bpmf`。恢復授權後，以一筆新的 `main` 提交確認自動部署連線；正式環境仍應使用上述根目錄靜態檔設定。
