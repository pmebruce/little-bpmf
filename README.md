# 小小ㄅㄆㄇ · 注音探險隊

給 5–7 歲孩子的互動注音 PWA，無帳號、無廣告、無付費 API。

## v2.2 新玩法
- 圖片尋寶島：先聽字詞、選圖片，答對才揭曉文字。初階二／三選一，第三階起還要選對應注音，兩步完成只算一題與一顆星。
- 選圖使用具體且可辨識的圖示，避免同圖不同名稱、同音或上下位名稱（例如船／輪船）同時成為答案。
- 注音偵探社：每題只改錯一個注音或聲調；先找錯誤位置，再選正確寫法修復。第一階先練聲調，第二階加入注音，第四階起練詞語。
- 一聲修復可移除多出的聲調記號；完整修復後才計一次獎勵。使用提示或重試仍獲得星星，另記為輔助完成。
- 首頁主按鈕改成混合小任務：選圖 → 拼音 → 偵探 → 聲調 → 選圖；仍可單獨選五種練習。
- 五種練習分別儲存自動難度與複習排程。從 v2.1 更新保留原本三種練習進度，補上新模式的起步狀態。

## 既有學習功能
- 96 個生活單字與詞語，分成動物、水果、食物、交通、日常用品、大自然六類；每類 16 個，可在首頁選主題。
- 拼音先看示範：點符號聽教育部錄音，再聽裝置朗讀完整字音，然後完成缺格或排列練習。
- 五階拼音：單字補注音 → 單字補音或聲調 → 單字排列 → 詞語補格 → 詞語排列。
- 雙字詞語一字一字完成，整個詞語完成後才計一次星星與學習紀錄。
- 五種練習各有獨立的自動難度；連續 3 題無提示且首次答對升一階，連續 2 題需要提示或重試降一階，上限五階、下限一階。
- 答錯時減少剩餘選項；拼音連續重試會回到示範，示範後的排列練習移除干擾積木。
- 需要提示或重試的題目排入複習，中間穿插至少兩個其他題目，且依當前主題與階段選題。
- 獨立答對與輔助完成分開統計；提示後答對仍有獎勵，不會推高難度。
- 每回合五題、動物貼紙、本機進度、每日目標、台灣中文語音選擇、可安裝圖示與離線快取。
- 保留 37 注音圖鑑、官方字形與逐筆顯示、手指自由描寫（不自動評分）。

## 發音與授權
37 個注音錄音內建，可離線播放。例字與聲調採裝置的 zh-TW / zh-Hant 語音，不以其他口音替代；沒有合適語音時顯示陪讀提示。字詞語音能否離線取決於裝置。

## 部署
延用既有 Cloudflare 靜態網站部署。根目錄就是網站輸出，無建置步驟、無依賴安裝；所有 URL 都使用相對路徑。GitHub Pages 子路徑同樣可用。

本機預覽：`python -m http.server 8000` 後開啟 `http://localhost:8000`。

## 進度與更新
v2 使用新的 `little-bpmf-v2` 儲存格式。v1 因符號對應錯誤，且點擊即加星，舊紀錄保留但不當成 v2 學習成果。

每次改版同步更新 `sw.js` 的 CACHE 版本。新版本完整快取後等待舊頁面關閉，避免遊戲中途混用兩版。安裝後請關閉所有舊分頁／主畫面 App，再重新開啟。資料不跨裝置同步；清除瀏覽器網站資料會移除進度。

5／6／7 歲選項現在只決定五種練習的初始階段（第一／第二／第三階），之後會依表現自動調整。重新選擇起步程度會重設難度與自動複習排程，保留星星、貼紙、已看示範及既有練習紀錄。舊 v2.0 進度會自動補上新的學習狀態，使用相同儲存鍵。

## v2.3：300 個分層字詞

- 入門 80、基礎 140、進階 80；各玩法第 1–2 階可練 80 個，第 3–4 階可練 220 個，第 5 階可練全部 300 個。聲調另依該階聲調種類篩選，圖片另限清楚圖示。
- 新題與圖片／注音選項都遵守分層；優先穿插新開放層級，複習仍依原間隔規則。
- 支援三字詞逐字拼音；完整詞語才記一次完成並給一顆星。輕聲記號置於音節前方。
- 保留 little-bpmf-v2 的星星、貼紙、程度、紀錄與複習佇列。

## v2.6：逐音拼讀提示

- 拼音答錯一次即可進入引導；點「聽聽怎麼拼」，依序播放既有教育部注音錄音並標亮，再以裝置台灣中文語音播放當前單字。多字詞逐字處理。
- 聲調不當作獨立注音符號發音，而在完整字音時同步標亮；一聲不加記號，輕聲維持原資料位置。
- 可停止、重播或直接「換我試試」；離開、換字及其他播放操作會取消未完成的播放。音訊失敗提供陪讀提示，不自動通過。
- 示範後重新產生作答選項／積木；保留既有 hadError 與 independent/assisted 紀錄，不把提示後完成算成獨立完成。初次必看的起步教學沿用既有規則。
- 不增加外部音訊依賴；字詞離線語音仍取決於裝置。儲存鍵及既有300字詞／複習資料不變。

## v2.7：跟著字音動一動

- 「聽聽怎麼拼」播放到的注音卡輕跳一次，完整字音播放時，注音由分散位置聚合成一個音節，圖片跟著點頭。答對流程不另加等待。
- 動畫跟隨 ready / sounds / blend / done 四個階段；停止、略過及離開會取消正在播放的階段。單點注音卡也有短暫提示動畫。
- 一段動畫最多約0.7秒，不循環、不閃爍、不改變頁面排版；系統啟用減少動態效果時保留靜態標亮。
- 這是拼讀提示的動畫，不是新增遊戲或題庫；裝置字詞語音仍須實機確認。
